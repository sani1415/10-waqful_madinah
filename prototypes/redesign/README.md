# নতুন নকশা — মকআপ (অক্টোবর ২০২৬)

`index.html` ব্রাউজারে খুলুন। এটা একটা স্বতন্ত্র পাতা: Supabase, লগইন বা আসল ছাত্রের তথ্য কিছুই এতে নেই, নামগুলো উদাহরণ মাত্র। অ্যাপের service worker-এর অংশও নয়।

**মূল ভাবনা:** যা শিক্ষকের সিদ্ধান্তের অপেক্ষায়, তা এক পর্দায় («আজ»); আর একজন ছাত্রের সবকিছু এক পাতায় (রিসালা · অগ্রগতি · বিবরণ · তথ্য)। ছাত্র অ্যাপও ৫ ট্যাব থেকে ৪-এ: আজ · রিসালা · খাতা · আমি। কোনো ধাপে ডাটাবেস বদলাতে হয় না।

**ডিজাইন:** উষ্ণ কাগজ-সাদা পটভূমি, গভীর সেজ-সবুজ মূল রং, «মনোযোগ দরকার»-এর জন্য মাখন-হলুদ; শিরোনামে Anek Bangla, লেখায় Hind Siliguri; মিহরাবের মতো খিলান আকৃতি আর হালকা আট-কোণা তারার নকশা হলো সিগনেচার। আইকন একটাই পরিবার (Lucide)। Reduced motion চালু থাকলে অ্যানিমেশন বন্ধ।

ছুঁয়ে দেখা যায়: শিক্ষকের «আজ»-এ অনুমোদন/পর্যালোচনা বাটন, ছাত্রের পাতার ট্যাব, ছাত্রের «আজ»-এ আমলের টিক, «খাতা»-র ট্যাব।
